Visual Page Builder's own map

This is the actual map code from the module (version 1.11), written from scratch with no outside libraries. Try it: drag (or flick) to move, pinch, double-tap, double-click, or use + and − to zoom, click a pin, use the arrow keys after clicking the map. The map pictures here are drawn stand-ins, because this page can't load outside images; on your site the same code shows real OpenStreetMap maps.

Map of places (as a walking tour)

Numbered stops joined in order. Click a pin for its note. The scroll wheel scrolls the page until you click the map.

    Story map

    Press Play: the map glides from stop to stop in date order while the pane tells each stop's story.
